# Duck Live emotion clips

Generated by `app/tools/make_animations.py`; do not edit by hand (edit the generator, rerun, commit).

| | |
|---|---|
| `manifest.json` | one entry per clip: name, label, emoji, key, duration, keyframes file, sound files, what it uses |
| `keyframes/<name>.json` | the motion, Pollen's format (below) |
| `sounds/*.wav` | the voice, 48 kHz mono; a clip with several voicings plays one at random |
| `LICENSE-pollen-microduck_emotions-apache-2.0` | licence of the Pollen files |

## Sources

- **Pollen Robotics, `microduck_emotions`** (https://github.com/pollen-robotics/microduck_emotions, Apache-2.0, commit
  in `manifest.json`): sad, devastated, curious, mmh, yes, yes_fast, no, defiant, angry, mock, excited, impatient,
  laugh, play_dead. Keyframes and wavs are byte-for-byte copies. `tools/quack.py` is their voice synth, also Apache-2.0.
- **Duck Live originals** (this repository): hello, happy, dance, sing, love, proud, showoff, peck, yawn, sneeze,
  startled, dizzy, nap. Motion from control points in `make_animations.py`, voice from `quack.py` with the robot's
  personality seed, beak lip-synced to the sound.

## Keyframe format

```json
{"keyframes": [{"t": 0.0, "neck": 0.0, "head_pitch": 0.1, "head_yaw": 0.0, "head_roll": 0.0,
                "body_pitch": 0.0, "body_z": 0.0, "mouth": 0.0, "twist": [0, 0, 0], "skill": null}, ...]}
```

Head values are offsets from the home pose in radians (`head_pitch` > 0 = beak down, `head_yaw` > 0 = to the duck's
left), `mouth` is 0..1, linear interpolation between samples, the clip ends at the last keyframe. A missing field is 0.
Fields this player reads beyond Pollen's: `twist` = (vx, vy, wz) for the walk policy, and the skills `"jump"` and
`"flip"` next to Pollen's `"sit"`. `body_pitch` is shown as extra head pitch and `body_z` is ignored (the body-pose
command is not usable on the current walk export; `docs/duck_live_animation.pdf`, experiment B).
